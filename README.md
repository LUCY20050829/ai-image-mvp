# AI 自动化生图 Web MVP

## 项目定位

本项目是面向教研老师的轻量 Web MVP，用于把诗歌和教研配图需求转成可批量生成的 AI 图片任务。产品目标是让老师通过网页勾选和少量补充要求完成生图，不需要使用 Codex，也不需要自己编写专业 Prompt。

当前阶段是本地可演示版，还不是正式部署版。

## 当前能力

- 支持结构化任务配置：学段、诗歌、画面人物、诗词文字、图片比例、生成数量。
- 支持从页面勾选多首诗歌，并按每首诗批量生成多张图。
- 支持三类学段画风：小低、小中小高、初中。
- 支持有人物 / 无人物、有诗词 / 无诗词的前端选项和后端生成逻辑。
- 支持 DeepSeek 生成专业生图 Prompt，再调用 image2 生成图片。
- 支持生成进度、成功 / 失败统计、结果卡片展示和点击预览。
- 默认生成结果先在前端展示，需要时再下载或保存到本地输出目录。

## 项目结构

```text
ai-image-mvp/
|-- server.py                  # 后端入口，提供 Web 页面和 API
|-- static/                    # 前端页面、样式和交互脚本
|-- workflow/                  # 原有 AI 生图 workflow 核心脚本
|-- prompt_assets/             # 系统提示词和学段画风规则
|-- assets/                    # 参考图、人脸图等资源
|-- generated_outputs/         # 生成输出、日志和可保存的图片
|-- backups/                   # 开发过程中的自动备份
|-- poems.xlsx                 # 前端诗歌数据来源之一
`-- .env.example               # 环境变量示例
```

## 前端说明

前端文件位于 `static/`。首页不再是自由聊天式界面，而是任务型工具页。老师可以先选择学段和诗歌，再选择画面是否出现人物、是否出现诗词文字，最后设置图片比例和生成数量。

“补充要求”是可选项，用于表达额外画面要求，例如色调更温暖、人物不要过于悲苦、画面更开阔等。

## 后端说明

后端入口是 `server.py`。它负责接收前端任务，读取诗歌数据、组装学段画风和生图规则，调用 DeepSeek 生成提示词，再调用 image2 生成图片。

如果选择“无人物”或“无诗词”，后端会先生成完整页面图，然后在该图基础上进行二次编辑，用来移除人物或移除诗词文字，以尽量保持构图和留白稳定。

## 本地运行

1. 进入项目目录：

```powershell
cd "D:\ai-image-mvp"
```

2. 启动后端：

```powershell
python server.py
```

3. 打开页面：

```text
http://127.0.0.1:8765
```

## 环境变量

项目需要在 `.env` 中配置模型调用所需的密钥。仓库中只保留 `.env.example`，不应把真实 API Key 提交到公共仓库或发给其他人。

## 输出与日志

- `generated_outputs/`：用于放置生成结果、任务日志和临时输出。
- `generated_outputs/job_summary.jsonl`：记录每次测试的时间、任务规模、成功数、失败数、耗时和状态。
- `测试记录/Web_MVP_测试记录.xlsx`：面向人阅读的测试复盘表。

## 开发备份
